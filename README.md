## 这是一本什么书？| What is this book?

这不是一本枯燥的技术教科书，而是一部**技术亲历者讲述的30年数字文明史诗**。

从1994年马克·安德森在NCSA机房写下第一行浏览器代码，到2026年OpenAI发布GPT-5——作者以第一人称视角，带你穿越浏览器战争、社交网络崛起、移动互联网爆发、AI大模型革命，直到机器人长出身体的具身智能时代。

This is not a dry technical textbook, but a **30-year epic of digital civilization told by a technology insider**.

From Marc Andreessen writing the first line of browser code in the NCSA server room in 1994, to OpenAI releasing GPT-5 in 2026—the author takes you through the browser wars, the rise of social networks, the explosion of mobile internet, the AI large model revolution, all the way to the era of embodied intelligence where robots grow bodies.

## 核心叙事框架 | Core Narrative Framework

### 双螺旋结构：软件与硬件的共舞 | Double Helix: The Dance of Software and Hardware

```
1994 ───────────────────────────────────────────► 2026

软件线：浏览器 → 搜索引擎 → 社交网络 → 电商 → 移动互联网 → AI
          ↑         ↑          ↑        ↑         ↑        ↑
硬件线：光缆 ─→ 服务器 ─→ 芯片 ─→ 传感器 ─→ 电池 ─→ 机器人
```

软件的每一次飞跃，都建立在硬件的突破之上。

Every leap in software is built upon breakthroughs in hardware.

### 双边市场：从免费到收租 | Two-Sided Markets: From Free to Rent Collection

```
用户 ────► 平台 ◄──── 商家/开发者
   ↑         ↓           ↑
   └──── 数据/价值 ──────┘
```

所有科技平台都遵循同样的剧本：补贴启动 → 飞轮旋转 → 平台收租 → 屠龙变恶龙

All tech platforms follow the same playbook: subsidy launch → flywheel rotation → platform rent collection → dragon-slayer becomes dragon.
