## Core Narrative Framework

### Double Helix: The Dance of Software and Hardware

```
1994 ───────────────────────────────────────────► 2026

Software: Browser → Search Engine → Social Network → E-commerce → Mobile Internet → AI
             ↑           ↑              ↑             ↑              ↑           ↑
Hardware: Fiber Optic → Servers → Chips → Sensors → Batteries → Robots
```

Every leap in software is built upon breakthroughs in hardware.

### Two-Sided Markets: From Free to Rent Collection

```
Users ────► Platform ◄──── Merchants/Developers
    ↑          ↓              ↑
    └──── Data/Value ─────────┘
```

All tech platforms follow the same playbook:

1. **Subsidy Launch**: Attract users with free services
2. **Flywheel Rotation**: More users bring more merchants; more merchants bring more users
3. **Platform Rent Collection**: Master traffic distribution rights, move from free to commission
4. **Dragon-Slayer Becomes Dragon**: Former disruptors become new monopolists
