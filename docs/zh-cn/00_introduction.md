# 引言：致那些改变世界的无名代码和燃烧的显卡

1994年12月的一个深夜，伊利诺伊大学香槟分校的国家超级计算应用中心（NCSA），马克·安德森盯着屏幕上闪烁的光标。他刚刚写完Mosaic浏览器的最后一行代码。窗外是中西部平原凛冽的寒风，机房里只有服务器风扇的嗡嗡声。他不知道，自己敲下的那些字符，即将撕开一个旧世界的裂缝。

二十九年后，2023年11月30日，旧金山OpenAI总部。山姆·奥特曼按下回车键，ChatGPT正式上线。服务器集群在俄勒冈州的数据中心里疯狂运转，英伟达A100芯片的温度飙升到80摄氏度。五天内，一百万用户涌入。

两段代码，两个时刻，中间隔着三十年。

这三十年里，世界被重写了三次。

第一次，浏览器撕碎了地理的围墙。信息开始像水一样流动。雅虎用人工分类目录搭建了互联网的第一座灯塔，亚马逊在车库里把书籍变成比特，eBay让陌生人之间建立起信任。硅谷发明了协议和标准，全世界跟进。中国在那个年代还在用拨号上网，56K调制解调器的尖叫声是那个时代最刺耳的背景音。

第二次，智能手机把传感器插进了全人类的口袋。2007年1月9日，乔布斯站在Macworld的舞台上，从信封里抽出那块没有键盘的玻璃。iPhone不是手机，是一个布满全球的神经末梢网络。GPS定位、加速度计、陀螺仪、摄像头——每一部手机都在向云端发送着位置、行为、偏好的实时数据。Uber用这些数据调度车辆，Airbnb用这些数据匹配房间，美团用这些数据计算骑手的最优路径。双边平台从"连接信息"进化到"调度物理世界"。这一次，中国不再只是跟随。滴滴在街头巷尾与Uber血战，美团在千团大战中杀出重围。更极端的环境、更密集的人口、更疯狂的资本，把O2O模式推到了硅谷都未曾想象的极限。

第三次，大模型把意图变成了代码。你不再需要学习如何使用软件，只需要说出你想要什么。Perplexity正在瓦解古典搜索的双边匹配，ChatGPT正在吞噬内容平台的流量入口。中介正在被谋杀。而这一次，世界裂变成了双核：美国在云端造神，统御着大模型的API网络；中国在泥地炼金，用精密制造和极致供应链，掌控着具身智能的物理躯干。

这本书，就是这三十年软硬交响史的记录。

我要讲的，不是那些光鲜的IPO钟声和市值曲线。我要讲的，是支撑那些万亿估值背后的底层代码、分布式数据库、高并发交易系统、以及埋在海底的光缆和燃烧的显卡。

我要讲的，是双边市场如何从消灭信息差的屠龙少年，异化为收租的垄断帝国。

我要讲的，是软件与硬件如何像DNA双螺旋一样纠缠上升——每一个伟大的应用背后，都站着一家芯片公司、一条通信标准、一座晶圆厂。

我要讲的，是硅谷如何在前二十年绝对引领，以及中国如何在后十年用工程化和供应链完成追赶，最终在AI时代形成双核格局。

这不是一本歌颂胜利者的书。这是一本解剖尸体的书。

因为只有看清那些死去的代码、破产的公司、被淘汰的技术路线，才能理解为什么是OpenAI而不是Google统治了大模型时代，为什么是英伟达而不是Intel掌握了算力霸权，为什么是字节跳动而不是Facebook发明了推荐算法驱动的短视频。

每一行代码都有它的宿命。每一块显卡都有它的温度。

让我们从1994年那个寒冷的冬夜开始。

那是网景碎玻璃的声音。
