## 这是一本什么书？

这不是一本枯燥的技术教科书，而是一部**技术亲历者讲述的30年数字文明史诗**。

从1994年马克·安德森在NCSA机房写下第一行浏览器代码，到2025年OpenAI发布GPT-5——作者以第一人称视角，带你穿越浏览器战争、社交网络崛起、移动互联网爆发、AI大模型革命，直到机器人长出身体的具身智能时代。

**你将读到：**

- 网景如何在90天内从巅峰坠落
- 马化腾如何在ICQ的 shadow 下做出QQ
- 贝佐斯和马云如何在地球两端同时点燃电商革命
- iPhone如何"杀死"键盘，重新定义人机交互
- 抖音的算法如何"绑架"你的注意力
- ChatGPT如何"谋杀"搜索引擎
- 特斯拉Optimus和宇树机器狗如何在泥地里炼金

**你将理解：**

- 为什么"网络效应"是科技公司的终极护城河
- 为什么所有平台最终都会从"屠龙少年"变成"恶龙"
- 为什么软件的每一次飞跃，都建立在硬件的突破之上

## 核心叙事框架

### 双螺旋结构：软件与硬件的共舞

```
1994 ───────────────────────────────────────────► 2026

软件线：浏览器 → 搜索引擎 → 社交网络 → 电商 → 移动互联网 → AI
          ↑         ↑          ↑        ↑         ↑        ↑
硬件线：光缆 ─→ 服务器 ─→ 芯片 ─→ 传感器 ─→ 电池 ─→ 机器人
```

软件的每一次飞跃，都建立在硬件的突破之上。

### 双边市场：从免费到收租

```
用户 ────► 平台 ◄──── 商家/开发者
   ↑         ↓           ↑
   └──── 数据/价值 ──────┘
```

所有科技平台都遵循同样的剧本：

1. **补贴启动**：用免费服务吸引用户
2. **飞轮旋转**：用户越多，商家越多；商家越多，用户越多
3. **平台收租**：掌握流量分配权，从免费到抽成
4. **屠龙变恶龙**：曾经的颠覆者成为新的垄断者
